使用說明 — TalentQuest 人才發展平台

版本：v1.0 ｜ 型態：單檔離線 HTML（瀏覽器直接開啟即可，亦可於手機瀏覽器使用）

一、兩種使用者角色

🧑‍💼 員工（玩家）

  • 開啟平台 → 右上角「目前玩家」選擇自己。
  • 「英雄旅程」就是你的角色卡：等級、經驗值、下一關任務清單。
  • 到「訓練課程」修課 → 完成後點「完成課程」獲得 XP。
  • 到「測驗中心」挑戰認證測驗 → ≥80 分通過，逐題解析幫你學會。
  • 三項門檻（XP／課程／測驗）全達成 → HR 會在「晉升評鑑」核准你升階。
  • 「徽章牆」收集成就，「英雄榜」看排名。

👔 HR／企業管理者

  • 「員工管理」建立員工（編號、部門、職系、頭像、起始職級）。
  • 「職級體系」設計你們公司的職業階梯：每級的 XP 門檻、指定課程、指定測驗。
  • 「職能地圖」維護職能字典與課程對應（16 項預設職能可增修）。
  • 「晉升評鑑」審核達標候選人 → 核准晉升（建議搭配面談與公開表揚）。
  • 「團隊總覽」掌握全員發展進度；「員工管理」可匯出 JSON 備份。

二、遊戲化機制速查

機制規則
XP 經驗值完成課程 +80~260；通過測驗 +（分數比例 × 卷面 XP）；晉升 +300
職級XP 達門檻＋修畢指定課程＋指定測驗 ≥80 分 → 晉升候選人 → HR 核准升階
徽章9 種自動頒發：初來乍到／學霸養成／學富五車／百分俱樂部／全能選手／一飛沖天／平步青雲／經驗老道／管理入門
測驗可重考，成績保留最高分；交卷後有逐題解析

三、資料與備份

  • 所有資料以 IndexedDB 儲存在本機瀏覽器，不上傳任何伺服器。
  • 備份：員工管理 → 匯出 JSON 備份（含全部名冊、課程、題庫、紀錄）。
  • 換裝置／換瀏覽器：資料不會跟著走，請先匯出備份再於新裝置匯入（或重新匯入 JSON）。
  • 清除瀏覽器資料會一併清除平台資料，請先備份。

四、常見問題

  • Q：可以多公司使用嗎？ 目前設計為單一公司、單機使用；多公司請各自部署或升級雲端版。
  • Q：員工會看到別人的資料嗎？ 平台為單機版，資料都在開啟的裝置上；建議由 HR 統一管理裝置與資料。
  • Q：可以改職級名稱嗎？ 可以——「職級體系」每級都可編輯名稱、XP 門檻、指定課程與測驗。
  • Q：題庫可以加題嗎？ v1.0 內建 50 題（8 卷）；自訂題庫請編輯 HTML 內的題庫資料或洽客服。
  • Q：離線可以用嗎？ 可以——單檔無外部依賴，沒網路照樣打卡學習。
