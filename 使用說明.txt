# 買賣業 ERP 系統 V2.2 — 使用說明

## 啟動方式（擇一）

### 方式一：雙擊 exe（免安裝，推薦）
雙擊 `dist\ERP系統_免費版.exe`，瀏覽器會自動開啟 ERP 系統。
關閉命令視窗即可停止伺服器。

### 方式二：雙擊 啟動ERP.bat
雙擊 `啟動ERP.bat`，會在預設瀏覽器直接開啟（file:// 模式，免伺服器）。
※ file:// 模式下 Excel 匯出匯入需網路載入元件；exe 模式則完全離線可用。

### 方式三：開發模式
```
python server.py            # 本機伺服器 + 自動開瀏覽器
python server.py --no-browser   # 純伺服器（測試用）
```

## V2.2 版本重點（2026-09-21）

- 新增「經營指標指數分析」模組（側欄 → 財務會計 → 🎯 經營指標指數分析）
  - 綜合經營指數（0～100）：獲利 35% ＋ 償債安全 25% ＋ 經營效率 25% ＋ 成長性 15%
  - 11 項經營指標：毛利率／營業利益率／純益率／流動比率／速動比率／負債比率／存貨週轉率／應收帳款週轉率／總資產週轉率／營收成長率／淨利成長率
  - 自動圖表：指數儀表、四構面雷達、月度營收與淨利趨勢圖
  - 智慧診斷與建議：依指標表現自動產生改善提醒
  - 一鍵匯出「經營指標指數分析」Excel
- 損益表工具列新增「列印」按鈕

## V2.1 版本重點（2026-08-28）

- 修復登入殘留代碼造成的 TypeError（任何輸入按 Enter 就會 crash）
- 刪除進貨/銷貨單時自動回滾/回補庫存
- 編輯進貨/銷貨單以「新舊差額」調整庫存
- 傳票編號改為同日流水號（同日多張不重複）
- 試算表/損益表/總帳統一含期初餘額，與資產負債表口徑一致
- 期初開帳差額自動入「累積盈虧 3252」科目
- 資產負債表新增「清除期初餘額」功能
- Excel 元件離線載入失敗時給出明確提示
- 側欄底部顯示公司名稱（系統初始化時自動帶入）

## 功能模組

### 財務會計
- 會計科目 — 220 個台灣標準科目（EAS）
- 傳票登錄 — 複式分錄、借貸平衡檢查、自動編號
- 總分類帳 — 依科目查詢明細與餘額
- 試算表 — 餘額式試算表（含期初）
- 損益表 — 期間損益 / 年度各月比較，可列印
- 資產負債表 — 含期初餘額匯入/清除
- 經營指標指數分析 — 綜合經營指數 + 11 項指標 + 圖表 + 智慧診斷

### 進銷存
- 商品主檔 / 供應商 / 客戶
- 採購進貨 — 自動入庫
- 銷售銷貨 — 庫存預警、自動扣減
- 庫存管理 — KPI 儀表板、安全存量警示

## 資料儲存
資料存本機瀏覽器 IndexedDB。請定期用「匯出」功能備份 Excel。
（注意：exe 與 bat 啟動的瀏覽器設定檔相同時，資料共用。）
