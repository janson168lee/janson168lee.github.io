【系統特色】
• 免安裝：雙擊 HTML 檔即可開啟，無需任何設定
• 免資料庫：所有資料儲存在瀏覽器本機，不上傳雲端
• 免月費：免費版完整功能，永久使用
• Excel 匯出匯入：所有資料均可匯出 Excel，不被綁架

【檔案清單】
1. 買賣業ERP系統.html — 會計 + 進銷存管理系統
2. 人力資源薪資系統.html — 人資 + 薪資管理系統
3. 使用說明.txt — 本檔案

【操作方式】

一、首次使用
  1. 雙擊「買賣業ERP系統.html」用瀏覽器開啟
  2. 在右側初始化面板輸入「公司名稱」
  3. 若有授權金鑰則填入（選填），無金鑰則為免費版
  4. 點「啟動系統」進入主畫面

二、會計作業流程
  步驟 1：設定期初餘額
    • 左側選「資產負債表」→ 點「匯入期初餘額」
    • 選擇 Excel 檔案（格式：日期 | 科目 | 借方金額 | 貸方金額）
    • 系統自動產生開帳傳票，借貸平衡自動驗證

  步驟 2：登錄日常傳票
    • 左側選「傳票登錄」→ 點「＋ 新增傳票」
    • 選擇日期、輸入摘要、選取科目、填入借貸金額
    • 借貸必須平衡才能儲存
    • 可整筆編輯：點「編輯」按鈕修改後儲存
    • 可整筆刪除：點「刪除」按鈕確認後刪除

  步驟 3：查看財務報表
    • 損益表：可選「年度比較」或「期間損益」
      - 只顯示金額≠0 的科目
      - 可匯出 Excel（含期間選擇）
      - 可列印（年度各月比較表 或 單月損益表）
    • 資產負債表：選擇日期時點
      - 只顯示金額≠0 的科目
      - 自動驗證 資產＝負債＋權益
    • 總分類帳：逐科目查詢每筆交易
    • 試算表：全科目借貸餘額一覽

三、會計科目管理
  • 系統內建 220 個台灣中小企業標準會計科目
  • 可新增、編輯、刪除科目
  • 所有科目初始值為 0，無任何預載傳票

四、進銷存作業
  • 商品主檔：新增/編輯/刪除商品，庫存自動追蹤
  • 採購進貨：新增進貨單，自動入庫更新庫存
  • 供應商/客戶管理：完整聯絡資訊管理
  • 庫存管理：安全存量預警、缺貨提示

五、人力資源薪資系統
  • 雙擊「人力資源薪資系統.html」獨立開啟
  • 員工資料管理、出勤、請假、加班
  • 每月薪資一鍵計算（含勞健保、勞退、所得稅）
  • 年度彙總、Excel 匯出匯入

【常見問題】

Q：打開後看到舊資料怎麼辦？
A：按 F12 → Application → Storage → Clear site data，再重整頁面。

Q：資料存在哪裡？
A：存在瀏覽器的 IndexedDB / localStorage，所有資料都在你的電腦上，
   不會上傳到任何伺服器。清除瀏覽器資料會刪除所有記錄，請記得
   定期用「匯出 Excel」備份。

Q：可以離線使用嗎？
A：可以。除了第一次載入 Excel 函式庫（SheetJS CDN）需要網路，
   之後完全離線可用。

Q：如何備份資料？
A：每個功能頁面都有「匯出 Excel」按鈕，定期匯出各模組資料即可。

Q：換電腦怎麼搬資料？
A：在舊電腦匯出 Excel → 複製 HTML 檔和 Excel 到新電腦 → 
   開啟 HTML → 匯入 Excel 即可。
